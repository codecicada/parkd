# Changelog

Notable changes to parkd, newest first. The format follows

[Semantic Versioning](https://semver.org/).

## [0.1.0] - Unreleased

### Added

- Park every tab of the current window as a dated group with one click.
- Restore one tab, one group, or everything.
- Reorder parked tabs by drag and drop, or with Alt+Up / Alt+Down.
- Import and export the list as plain `URL | title` text.
